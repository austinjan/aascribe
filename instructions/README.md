# instructions

Topic-based instructions for work in this repository. Start with `../AGENTS.md`, then read the topic file that matches the current task.

## Topics

- `testing.md`: test writing, mocking, fixtures, schema validation, and verification commands.
- `development.md`: coding workflow, docs synchronization, project state updates, and git staging rules.
- `deployment.md`: local builds, release builds, binary output, bundled skill installation, and release validation.

## Maintenance Rule

When a repeated workflow becomes project policy, update the matching topic file instead of burying the rule in chat history.
